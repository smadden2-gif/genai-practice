# GenAI Practice

A repository for small AI product experiments. Its first project is **Continuity**, a single-file venture concept website.

## Continuity

**Lower the cost of saying yes.**

Continuity explores an AI layer that helps people act on opportunities while keeping existing commitments moving. The page covers the problem, a seven-step product flow, the Opportunity Engine and Continuity layers, and a three-month startup program example.

- [View the live concept site](https://continuity.simonmaddenbcc.chatgpt.site)
- [View the source](index.html)

## Run locally

Download or clone this repository, then open `index.html` in a browser. No build step, package installation, or server is required. The page uses inline CSS and JavaScript; Lexend is loaded from Google Fonts when online.

```bash
git clone https://github.com/smadden2-gif/genai-practice.git
cd genai-practice
open index.html
```

On Windows, double-click `index.html` after cloning or downloading the repository.

## Current status

This is a **venture concept and static prototype**, not a working agent product. The email form demonstrates the interface but does not store or send submissions. The opportunity chart is illustrative, not measured data.

The live concept site and this GitHub repository are separate copies. Changes committed here do **not** automatically publish to the live site.
